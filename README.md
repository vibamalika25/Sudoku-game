
# 🧩 Sudoku Game

A modern, interactive Sudoku web application built with React. Challenge yourself with daily puzzles, track your progress, and compete on the leaderboard!

🔗 **Live Demo**: [https://sudoku-game-1-4hiq.onrender.com](https://sudoku-game-1-4hiq.onrender.com)

## ✨ Features

- 🎲 **New Game** – Start a fresh Sudoku puzzle at any time
- 📊 **Progress Tracking** – See your completion percentage
- 🔥 **Streak Counter** – Track your daily playing streak
- 🏆 **Leaderboard** – Compete with other players (coming soon)
- 🎨 **Beautiful UI** – Smooth animations and responsive design
- 📱 **Mobile Friendly** – Play on any device

## 🛠️ Technologies Used

- **React** – Frontend framework
- **React Router** – Navigation between pages
- **CSS3** – Custom styling with animations
- **Render** – Hosting and deployment

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/vibamalika25/Sudoku-game.git
   cd Sudoku-game
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Visit `http://localhost:3000` to play the game

### Build for Production

```bash
npm run build
```
